# Código de conduta

Isto se aplica a todos que participam deste projeto: issues, Discussions, pull requests,
revisões, e qualquer outro canal que o projeto use.

## Esperado

- Presuma boa fé. A maioria dos desacordos aqui é sobre o que um agente deveria fazer, e pessoas
  razoáveis divergem.
- Critique o trabalho, não a pessoa. "Essa regra vai disparar em todo turno e custar contexto" é
  útil; "você claramente não entende de agentes" não é.
- Mantenha no assunto e mantenha concreto. Um exemplo vale mais que um adjetivo.
- Diga quando você estava errado. Este repositório é construído sobre a ideia de que um status honesto vale
  mais que um polido.

## Não aceitável

- Assédio, insultos ou ataques pessoais de qualquer tipo, incluindo com base em quem alguém
  é.
- Publicar informação privada de outra pessoa, como um endereço residencial ou um e-mail privado,
  sem a permissão explícita dela.
- Perturbação sustentada de uma thread depois de ter sido pedido para parar.
- Qualquer comportamento que razoavelmente faça alguém se sentir inseguro ou não bem-vindo para contribuir.

## Como reportar

Reporte de forma privada ao mantenedor através do endereço de e-mail no perfil do GitHub do
mantenedor, ou use os links de "report content" do GitHub no item ofensivo. Reportes são lidos dentro de
uma semana e mantidos confidenciais.

## Aplicação

O mantenedor decide o que acontece, em proporção ao que aconteceu: uma nota privada, um aviso
público, um bloqueio temporário, ou um bloqueio permanente do projeto. Decisões são finais para
este projeto.
