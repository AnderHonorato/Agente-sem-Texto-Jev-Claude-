# Comparando harnesses

Esta página foi movida. As propriedades que valem a pena comparar, os projetos que as têm hoje, e
as próprias lacunas deste repositório estão no [levantamento de campo](field-scan.md) datado, que é
reverificado periodicamente e substituído em vez de emendado.

A única linha que vale a pena manter da versão antiga: envie uma comparação, ou um contraexemplo,
como uma [issue de Ideia](https://github.com/JakeSelby/agent-harness/issues/new/choose). O objetivo
de publicar o harness é descobrir quais das suas afirmações se sustentam fora do fluxo de trabalho
de uma única pessoa.
