# Postura de custo: máxima

O esforço da sessão fica no padrão do modelo, o fan-out é tão amplo quanto a tarefa exigir, o
modo rápido é permitido, a compactação é permitida quando uma tarefa longa precisa, e o feed nunca
te empurra a começar uma sessão nova. Otimize para a resposta, não para a conta. A tabela
precifica cada papel e banda: classe, esforço, orçamento. O tier vem de `delegation`; esta define
quanto. Os custos de `cache-hygiene.md` se aplicam; você escolhe pagá-los.
