# Suporte

Comece por [docs/getting-started.md](docs/getting-started.md): pré-requisitos, instalação, uma primeira
sessão, o que ela custa, e os três comandos que diagnosticam uma sessão quebrada. A maioria das primeiras perguntas
já é respondida ali, e `bin/harness doctor` responde a maior parte do resto.

Tudo abaixo exige uma conta do GitHub e é público.

- **Perguntas** ("como eu faço...", "por que o agente...") → [Discussions, Q&A](../../discussions/categories/q-a).
- **Bugs** no instalador, num hook, ou numa regra que dispara errado → uma
  [issue de Bug](../../issues/new?template=01-bug.yml) com a saída de `bin/harness doctor`.
- **Ideias** → uma [issue de Ideia](../../issues/new?template=02-idea.yml) ou
  [Discussions, Ideas](../../discussions/categories/ideas).
- **Segurança** → veja `SECURITY.md`; nunca uma issue pública.

Não existe canal de suporte privado. Tudo acontece em aberto para que a próxima pessoa consiga
encontrar.
