# Proveniência

Todo arquivo aqui foi escrito ou reescrito para este repositório, em segunda pessoa, sem nada
pessoal restante nele. Esta página registra de onde vieram as ideias, como histórico.

- **Regras principais** (`working-style`, `decisions-and-plans`, `delegation`, `transcript-hygiene`,
  `voice-and-format`, `research-and-verification`) surgiram de um diretório pessoal de regras
  construído ao longo de um ano rodando agentes de código, a maior parte no Cursor e os últimos
  dois meses no Claude Code, em um jogo de estratégia (Sovereign), um aplicativo de assistente
  executivo (Consul), um servidor MCP de governança (Cortex), e trabalho voluntário com dados.
- **`conciseness` e `verification`** foram escritas originalmente como regras para contribuidores
  convidados de um fork de uma biblioteca open-source de pipeline de dados, onde o custo de um PR
  descuidado é o tempo de outra pessoa.
- **`secrets`** e a skill **`migration-safety`** vieram do ferramental de uma equipe voluntária,
  onde o staging continha dados reais.
- **A postura `testing`** veio de um repositório de planejamento de ideias de produto; a **postura
  `autonomy`** veio das próprias regras do servidor de governança e de uma configuração do Codex.
- **As skills `worktree-per-agent` e `spike-contract`** vieram das instruções do repositório do
  jogo de estratégia (Sovereign), onde vários agentes trabalhavam no mesmo checkout e os spikes
  precisavam ser lidos contra números medidos.
- **A skill `design-loop`** é derivada do [dream-loop](https://github.com/achimala/dream-loop)
  (MIT); veja `THIRD_PARTY_NOTICES.md`.
- **O validador de plan-card e o hook somente leitura** foram escritos para este harness depois de
  muitos prompts de permissão no modo plano e muitos planos que ninguém conseguia revisar em uma
  única tela.

A auditoria que decidiu o que trazer e o que deixar de fora está resumida nas propriedades de
[field-scan.md](field-scan.md): qualquer coisa que fosse verdadeira apenas para uma pessoa, um
projeto ou um empregador ficou de fora.
